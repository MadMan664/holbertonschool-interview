# Lockboxes

Given `n` locked boxes numbered `0` to `n - 1`, where each box may
contain keys to the other boxes, determine whether every box can be
opened. The first box, `boxes[0]`, is unlocked, and a key with the same
number as a box opens that box. Keys that have no matching box are
ignored.

## Tasks

0. `0-lockboxes.py` - `canUnlockAll(boxes)` returns `True` if all the
   boxes can be opened, otherwise `False`.
